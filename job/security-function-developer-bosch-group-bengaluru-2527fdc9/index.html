Security Function developer

Bosch Group · Bengaluru

About the role

Bosch Global Software Technologies Private Limited is a 100% owned subsidiary of Robert Bosch GmbH, one of the world's leading global supplier of technology and services, offering end-to-end Engineering, IT and Business Solutions. With over 27,000+ associates, it’s the largest software development center of Bosch, outside Germany, indicating that it is the Technology Powerhouse of Bosch in India with a global footprint and presence in the US, Europe and the Asia Pacific region. Role: Are you passionate about developing state-of-the-art Cyber security solutions for different Automotive control units? Spanning across Engine ECU, VCU, Battery Management, Fuel cell control, charging control, Inverter control etc.With increased security vulnerability for embedded products, improving Security in automotive world is a key challenge worldwide. Our team focuses on understanding security needs, developing platform and customer specific security solutions, analyzing threat and risk and developing robust security test methodology. Analysis of security requirements from OEM'sEngage with OEM Cyber security expert to explain security concepts and security features based on requirementsProvide guidance to projects/OEM’s for implementation of Security Engineering Process Development of security concepts (Threat and Risk analysis – cycurRisk) Responsible for implementation of security infrastructure software, security features and support in realization of cyber security in customer projects Security configurations and function development based on Hardware Security Module (HSM), cycurHSM Configuration of Autosar security modules (CSM, CryIF, SecOC, KeyM etc.) Function development using C programming language on Electronic Control Units with Multi-core micro-controllers (Tricore AURIX, ST etc.) Development/support in security test concepts/strategies, test automationWhat the person brings in:  Capable of handling external/internal stakeholders like Customer team, OEM to explain security concepts and security features Should have strong knowledge on micro-controllers: Infineon, ST Strong development experience in embedded C, RTOS Good understanding of security concepts driven from cycurRiskStrong development experience of security features with security stacks like cycurHSMStrong development experience non Autosar stack- custom Secure boot, secure communication etc.Need to have knowledge in Hardware security will be added advantage Version Control Systems – SDOM / SVN /GIT etcExperience in scripting languages like Perl / CAPL / Python etc. is an added advantage BE Electronics 8
