Linux Integration and Automation Engineer

Intel · Bengaluru

About the role

Job Details: Job Description: We are looking for a talented Linux Integration and Automation Engineer experienced in Linux environments, system/software integration and automation. The engineer will be responsible for integrating and maintaining Linux-based software environments, developing automation solutions, improving build and validation workflows, and troubleshooting integration and system-level issues. The role will also actively leverage Generative AI and AI-assisted engineering to improve automation, debugging, failure analysis, and developer productivity. The ideal candidate should have strong hands-on experience with Linux, Python, Shell scripting, Git, CI/CD, APIs, and containers, along with practical experience using GenAI/LLM technologies and AI-assisted development tools. Business group This role is part of Intel Corporation, a global leader in technology innovation driving advancements that impact the way people live, work, and play. The team focuses on delivering end-to-end software integration strategies and solutions that support Intel's mission to shape the future of computing and connectivity. Working within this group provides opportunities to engage in meaningful projects, contribute to cutting-edge developments, and support Intel's broader goals of innovation and excellence. Key

Responsibilities

Linux Integration

Define and execute platform software integration strategies that ensure readiness for release.

Manage and track software ingredient in-delivery timelines to maintain mainline health.

Integrate, configure, validate, and maintain Linux-based software environments and platform components.

Integrate software packages, libraries, drivers, tools, and platform dependencies.

Support Linux distribution upgrades, package updates, and environment migration.

Troubleshoot Linux system, boot, package, dependency, configuration, networking, and integration issues.

Perform root-cause analysis using system logs, traces, and other diagnostic information.

Record release cadences, manage external release BOMs (Bill of Materials), and support external customer software releases.

Partner with cross-functional teams to drive project branching strategies and maintain software quality. Automation and Tools Development

Develop automation using Python and Bash/Shell scripting.

Automate environment setup, builds, integration, deployment, validation, log analysis, and reporting.

Develop reusable automation frameworks, utilities, and self-service solutions.

Integrate engineering tools and services using REST APIs.

Identify repetitive engineering activities and replace them with scalable automated workflows. CI/CD and DevOps

Work with DevOps team to develop and maintain CI/CD pipelines using Jenkins, GitLab CI/CD, GitHub Actions, or equivalent platforms.

Automate build, integration, testing, packaging, deployment, and release workflows.

Troubleshoot pipeline and infrastructure failures and implement recovery mechanisms.

Work with Git-based development, branching, code reviews, and release workflows. GenAI and AI-Assisted Automation

Apply Generative AI and LLM-based technologies to engineering and automation use cases.

Develop AI-assisted solutions for log analysis, failure classification, debugging, root-cause analysis, and issue summarization.

Use GenAI to enhance existing automation frameworks and engineering workflows.

Develop scripts/tools that interact with LLM APIs and AI services.

Apply prompt engineering techniques to build reliable engineering-oriented GenAI solutions.

Explore RAG, AI agents, tool/function calling, and agentic workflows for engineering automation.

Use AI-assisted development tools such as GitHub Copilot or equivalent solutions to accelerate development and troubleshooting.

Evaluate GenAI solutions for accuracy, reliability, security, and practical engineering value.

Qualifications

Qualifications

BTech or MTech or Equivalent degree in the field of Computer Science or related fields with 4+ years of relevant experience Preferred Skills:

Experience with Ubuntu, RHEL, CentOS Stream, Fedora, or similar Linux distributions. Strong Linux fundamentals, processes, services, permissions, package management, filesystems and networking.

Knowledge of APT/DEB, DNF/YUM/RPM package management.

Linux software/package integration, dependency management.

Experience with developing internal workflow automation tools, portals, dashboards, or self-service platforms. Strong Python programming and Bash/Shell scripting.

Git, branching, pull/merge requests.

Linux/system troubleshooting, log analysis and root-cause analysis.

Experience with Ansible or similar configuration-management frameworks.

Experience with GenAI frameworks such as LangChain, LangGraph, Semantic Kernel, or equivalent.

Familiarity with vector databases, embeddings, and Retrieval-Augmented Generation (RAG).

Experience building AI agents or integrating LLMs with existing engineering tools/APIs.

Understanding of responsible AI practices, including data privacy and secure usage of enterprise data with LLMs. Additional Skills (exposure to the following would be beneficial, but should not be treated as mandatory hiring criteria):

Knowledge of Intel IFWI firmware architecture

Experience with Agentic AI pipelines for workflow automation
