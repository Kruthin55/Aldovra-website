Software Engineer (Python AND Angular)

NielsenIQ · Chennai

About the role

About Job We are seeking a motivated Associate Software Engineer with strong fundamentals in Angular and Python development. The candidate will be responsible for designing, developing, testing, and maintaining web applications, including responsive user interfaces, backend services, and REST APIs. The role involves working closely with senior engineers, business analysts, and QA teams to deliver reliable, scalable, and high-quality software solutions. The ideal candidate should have a good understanding of modern web development practices, clean coding principles, and application performance optimization.

Responsibilities

Design, develop, and maintain web applications using Angular and Python. Build responsive UI components and RESTful APIs. Write clean, scalable, and maintainable code. Collaborate with cross-functional teams to deliver high-quality solutions. Troubleshoot, debug, and optimize application performance. Participate in code reviews, testing, and deployment activities. 3-5 years of software development experience. Strong hands-on experience with Angular, TypeScript, HTML, CSS, and Python. Experience with REST APIs, SQL databases, and Git. Understanding of software design principles and agile methodologies. Good problem-solving and communication skills. Our
