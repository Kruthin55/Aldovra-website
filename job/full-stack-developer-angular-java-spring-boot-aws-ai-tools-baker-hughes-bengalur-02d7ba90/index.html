About the role

Are you a highly motivated, creative individual and passionate about technology and development? Would you like to be a part of successful team? Join our team! Baker Hughes is the leading energy technology company, who delivers across the energy value chain through our market-leading business segments. Built on a century of experience and conducting business in over 120 countries. Our innovative technologies and services are taking energy forward! Making it safer, cleaner and more efficient for people and the planet. As a Full Stack Developer for Baker Hughes , you will be responsible for building and enhancing modern full-stack web applications. This role requires strong hands-on experience in Angular-based frontend development, along with backend development experience using Node.js and/or Java Spring Boot. This is a hands-on individual contributor role, working closely with product, QA, architecture, platform and DevOps teams to deliver secure, scalable and maintainable digital solutions. The role also requires openness to using AI-assisted development tools and modern engineering practices to improve productivity, code quality and delivery speed. Building modern, responsive and maintainable web applications using Angular, TypeScript and JavaScript Developing backend services using Java Spring Boot Designing, consuming and integrating REST APIs to support full-stack application workflows Owning end-to-end feature development across frontend, backend, testing and deployment support Using AI-assisted development tools where appropriate to improve productivity, code quality, debugging, testing or documentation Applying clean code practices, frontend/backend architecture, reusable components and design pattern principles Building performant, scalable and maintainable solutions aligned to technical standards and architecture guidelines Working with AWS cloud infrastructure or similar cloud platforms and cloud-native concepts Supporting CI/CD pipelines using tools such as Jenkins, GitHub Actions, GitLab or Azure DevOps Writing unit tests and supporting code quality practices using tools such as SonarQube or equivalent Following secure coding practices and supporting remediation of findings from SAST, DAST, OSS scans or vulnerability assessments Working in Agile/Scrum teams with strong collaboration across product, QA, platform and business stakeholders Nice to have: Python knowledge and experience supporting automation, scripting or data-related use cases Fuel your passion! To be successful in this role you will have: At-least 5+ years hands-on software development experience Strong Angular experience (recent Angular versions preferred) Backend experience in Java Spring Boot Good to have a strong TypeScript / JavaScript experience Experience with REST APIs / backend integration Exposure to AWS Should have worked on full-stack development (Frontend plus backend/API work) Uses AI tools for development productivity (GitHub Copilot, ChatGPT, Claude, Cursor, Cline, OpenCode, Claude Code or similar) Experience with CI/CD tools ( GitHub Actions, GitLab, Azure DevOps ) Has worked on end-to-end feature development (from requirement to development, testing, deployment or production support ) Familiarity with unit testing / code quality practices (Jasmine, Jest, ViTest, Karma, JUnit, SonarQube, code reviews ) Awareness of secure coding / security scans (SAST, DAST, OSS scans, vulnerability fixes) Comfortable using AI tools for coding, debugging, unit test generation, refactoring or documentation Work in a way that works for you We recognize that everyone is different and that the way in which people want to work and deliver at their best is different for everyone too.
