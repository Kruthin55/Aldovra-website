Software Engineer I, Full Stack (Frontend Focused) (Bangalore, India)

AiPrise · Bengaluru

About the role

ABOUT AIPRISE AiPrise is a global compliance orchestration platform helping fintechs, marketplaces, and payment companies verify and onboard customers worldwide. We integrate with 80+ identity and compliance vendors to deliver a holistic view of risk. We're now building AI-powered compliance agents to revolutionize KYB, AML, sanctions screening, and risk scoring, enabling our customers to onboard faster, reduce manual reviews, and prevent financial crime. ROLE OVERVIEW We're hiring a frontend-focused Full Stack Software Engineer I: strong on the frontend and comfortable across the stack. This is a build it, ship it, own it role. You'll take features end to end, from design to code to deploy to iterate. Most of your work will be on what our customers and their users see: the onboarding flow end users go through, our Web, Flutter and React Native SDKs, and the case management product compliance teams use every day. You'll also build the APIs and backend changes these features need. You'll work closely with founders, product and design, turning messy real world compliance problems into simple, reliable products. WHAT YOU'LL DO BUILD & OWN FEATURES END-TO-END - Design, build, and ship product features across the stack, with a focus on the frontend - Own features from requirements → implementation → deployment → monitoring - Build onboarding flows for KYC and KYB, including forms, document upload, ID capture, selfie and liveness - Make these flows work well on all kinds of phones and browsers, and inside customer apps through our SDKs - Build the backend APIs and data changes your features need DRIVE TECHNICAL EXCELLENCE - Write clean, maintainable, well-tested code - Keep the product fast and stable, including on low-end devices and slow networks - Debug production issues with urgency; own them until they're fixed - Participate in code reviews and help improve how we build and release COLLABORATE - Work cross-functionally with product, design, compliance and customer success teams - Think about the full user journey, and suggest better ways to solve a problem, not just build what is asked - Contribute to technical decision-making and help shape engineering culture as the team scales WHAT WE'RE LOOKING FOR MUST-HAVE: - 0-2 years of professional experience building and shipping production software - Strong TypeScript and React, including performance and state management - Good HTML and CSS, with responsive, mobile-first layouts - Experience building REST APIs in a backend language like Python or Node.js, and working with relational databases - Good product and UX sense - Strong debugging and problem-solving skills; comfortable working in unfamiliar codebases - Clear communication NICE-TO-HAVE: - Experience with mobile web, camera or media APIs, and cross-browser issues - Flutter or React Native experience, or experience building SDKs and libraries - Experience with web performance and frontend testing tools - Experience in FinTech, RegTech, payments or identity verification - Hands-on experience with AWS, CI/CD and Docker WHY AIPRISE - Build mission-critical software that directly fights financial crime and fraud for companies like Meta and leading fintechs - Work with users and data from 200+ countries - Join a fast-moving YC-backed startup where your work has immediate customer impact - Ship quickly. Your code will reach production in days, not months - Collaborate in-person with a talented, mission-driven team in Bengaluru - Competitive compensation ABOUT THE INTERVIEW 1. Remote: Frontend Fundamentals (a technical discussion that may include a short coding exercise) 2. In-office 1. DSA / Problem Solving 2. Frontend Machine Coding 3. Frontend System Design 4. Behavioural 5. Remote: Compensation Discussion
