Software Engineer

Fidelity Investments · Bengaluru

About the role

Job Description: Job Title – SOFTWARE ENGINEER The Purpose of This Role Fidelity Investments Enterprise Infrastructure is seeking a Software Engineer to design, build, modernize and support secure automation solutions and web applications that simplify IT operations. The role combines strong .NET and Python engineering with disciplined DevOps practices, production support, and a compliance-first approach to software delivery. You will collaborate with technology partners to translate operational needs into maintainable, observable and scalable solutions. Exposure to AI-assisted engineering, intelligent automation or Generative AI is an added advantage. The role is based in Bengaluru, India. The Value You Deliver

Design, develop and maintain reliable applications, APIs, automation services and utilities using .NET and Python.

Build solutions that reduce manual IT operations through workflow automation, self-service and reusable engineering patterns.

Own engineering quality across requirements, design, development, code review, testing, deployment, monitoring, support and continuous improvement.

Embed DevOps practices through source control, automated builds, CI/CD, repeatable deployments, environment configuration, observability and operational readiness.

Follow secure software development, change management, vulnerability remediation, auditability and applicable enterprise compliance requirements as part of day-to-day engineering.

Partner with infrastructure, security, risk and business teams to ensure solutions are supportable and aligned with technology standards and roadmaps.

Diagnose production issues, perform root-cause analysis and implement durable remediation.

Contribute to Agile planning, technical documentation, knowledge sharing and continuous improvement.

Evaluate modern engineering capabilities, including AI-assisted development and intelligent automation, where they improve productivity or solution quality. The Skills That Are Key to This Role

Hands-on application development using C#, .NET / modern .NET and ASP.NET Core, including RESTful APIs and service integration.

Strong Python programming skills for automation, APIs, data processing or backend services.

Solid software engineering fundamentals: object-oriented design, API design, error handling, logging, unit/integration testing, debugging and code quality.

Working knowledge of relational databases and SQL, such as SQL Server, PostgreSQL or MySQL.

Practical experience with Git-based source control and collaborative code-review workflows.

Strong understanding of CI/CD using tools such as Jenkins, GitHub Actions or equivalent enterprise pipelines, including automated quality and security checks.

Experience packaging and deploying applications using Docker; familiarity with Kubernetes or container orchestration is valuable.

Understanding of configuration and secrets management, release controls, rollback/recovery, monitoring and production support.

Awareness of secure coding, dependency/vulnerability management and the importance of SDLC, change-control, risk and compliance evidence throughout delivery.

Ability to communicate clearly, work across teams and learn new technologies quickly. DevOps, Security & Compliance Expectations

Treat CI/CD, automated testing, security scanning and deployment validation as foundational engineering controls.

Maintain traceability from source change through build, approval and deployment, with clear documentation and auditable evidence where required.

Use approved patterns for secrets, privileged access, dependencies and environment configuration; avoid hard-coded credentials or unmanaged configuration.

Build observability through structured logging, health checks, actionable monitoring and support documentation.

Address vulnerabilities, technical debt and operational risks with the same ownership as functional defects.

Design for controlled, repeatable releases with appropriate environment separation and recovery/rollback considerations. Skills That Are Good to Have / Added Advantage

AI / Generative AI exposure, such as AI-assisted workflows, enterprise-approved LLM services, prompt engineering, Retrieval-Augmented Generation (RAG), evaluation or responsible AI practices.

Experience using AI coding assistants while maintaining code-review, security, IP and compliance controls.

Cloud engineering experience with Azure or AWS, including application hosting, managed services or migration patterns.

Experience with Infrastructure as Code and automation tooling such as Terraform, PowerShell or equivalent.

Working knowledge of microservices, event-driven integration or distributed application patterns.

Working knowledge of Java and the Spring / Spring Boot ecosystem for backend services, APIs or enterprise application development.

Front-end development experience with modern Angular, TypeScript, HTML and CSS. How Your Work Impacts the Organization FITG (FMR India Technology Group) supports IT capabilities and technology delivery for Fidelity India. In this role, you will help improve engineering productivity and operational resilience by replacing manual activities with well-engineered, supportable automation. Strong DevOps and compliance practices are central to this impact: they help solutions move from development to production in a controlled, repeatable and auditable manner while remaining secure and maintainable. The Expertise We’re Looking For

2 to 4 years of relevant software development or engineering experience.

B.E., B.Tech., M.Tech. or equivalent relevant qualification/experience.

Demonstrated hands-on delivery in .NET and/or Python across the application lifecycle.

Practical ownership mindset for production quality, DevOps discipline, security and compliance. Location : Bangalore Shift : 11:00 AM to 8:00 PM Certifications: Category: Information Technology
