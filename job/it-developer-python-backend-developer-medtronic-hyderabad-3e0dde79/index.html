IT Developer - Python Backend Developer

Medtronic · Hyderabad

About the role

Careers that change lives start here. Medtronic is a global leader in healthcare technology with a Mission to alleviate pain, restore health, and extend life. Our 95,000 employees work across more than 150 countries to put patients first — developing innovative medical technologies that improve the lives of 72+ million patients each year. Your unique talents will help shape the future of healthcare while building a career grounded in purpose, growth, and impact. A Day in the Life The IT Developer (Python Backend Developer) will design, develop, and support enterprise-grade backend services for an AI-enabled platform ecosystem. The role focuses on building scalable APIs, distributed services, AI integrations, and platform capabilities that support large language models, agentic workflows, retrieval-augmented generation, observability, and enterprise integrations. This position requires strong Python engineering expertise, experience with cloud-native technologies, and a focus on reliability, security, and operational excellence.

Responsibilities

may include the following and other duties may be assigned. Design, develop, test, and maintain scalable backend services using Python and modern web frameworks such as FastAPI. Build secure REST APIs, asynchronous services, and reusable platform components using microservices and distributed-system architectures. Integrate backend services with large language models (LLMs), OpenAI-compatible APIs, model-serving platforms, and AI infrastructure. Develop platform capabilities supporting AI agents, retrieval-augmented generation (RAG), prompt management, Model Context Protocol (MCP), scheduling, notifications, and event-driven workflows. Implement background processing and messaging solutions using technologies such as Redis, Kafka, Celery, or equivalent platforms. Deploy and support containerized applications using Docker and Kubernetes while maintaining CI/CD quality standards. Implement observability capabilities including logging, metrics, tracing, monitoring, and operational dashboards. Perform code reviews, contribute to architecture decisions, troubleshoot production issues, and mentor junior engineers. Required Knowledge and Expertise: 3+ years of IT experience with a Bachelor's Degree in Engineering, MCA, or MSc with strong Python backend engineering expertise. Experience building REST APIs using FastAPI, Flask, Django, or comparable Python frameworks. Experience with distributed systems, microservices architectures, PostgreSQL, SQLAlchemy or equivalent ORM technologies, and Redis. Experience with Docker, Linux, CI/CD pipelines, automated testing using pytest, and Kubernetes or equivalent container orchestration platforms. Experience integrating applications with LLM APIs, AI services, messaging platforms such as Kafka or RabbitMQ, and enterprise security controls including OAuth 2.0, OpenID Connect (OIDC), and JSON Web Tokens (JWT). Nice To Have: Experience building AI platforms, AIOps solutions, internal developer platforms, or reusable enterprise platform services. Experience with retrieval-augmented generation (RAG), embeddings, vector databases, vector-enabled PostgreSQL, and prompt management frameworks. Experience with Model Context Protocol (MCP), agent orchestration, tool calling, and AI workflow automation. Experience with OpenTelemetry, Prometheus, Grafana, distributed tracing, centralized logging, and production observability practices. Experience supporting model-serving infrastructure, GPU-enabled workloads, Kubernetes-based AI platforms, or S3-compatible storage technologies such as MinIO. Physical Job
