Software Engineer I, Frontend (Bangalore, India)

AiPrise · Bengaluru

About the role

ABOUT AIPRISE AiPrise is a global compliance orchestration platform helping fintechs, marketplaces, and payment companies verify and onboard customers worldwide. We integrate with 80+ identity and compliance vendors to deliver a holistic view of risk. We're now building AI-powered compliance agents to revolutionize KYB, AML, sanctions screening, and risk scoring, enabling our customers to onboard faster, reduce manual reviews, and prevent financial crime. ROLE OVERVIEW We're hiring a Software Engineer I, Frontend to own the onboarding flow, the part of AiPrise that end users actually see. Users enter their details, scan an ID, take a selfie and upload documents. The flow is a React app, and customers embed it in their own products through our Web, Flutter and React Native SDKs. Every customer configures their own steps, theme and language, so one codebase has to work well for many setups, on every kind of phone and browser. This is a build it, ship it, own it role. It's a small team, and you'll own large parts of the flow from day one. WHAT YOU'LL DO BUILD & OWN THE ONBOARDING FLOW - Build and improve onboarding screens for individuals (KYC) and businesses (KYB) - Build camera features like ID capture, selfie and liveness, and make them reliable on iPhones, low-end Android phones and inside mobile apps - Maintain and improve our Web, Flutter and React Native SDKs so the flow feels native inside customer apps DRIVE TECHNICAL EXCELLENCE - Keep the flow fast and stable, including on low-end devices and slow networks - Use data to find and fix where users drop off - Write clean, well-tested code and take part in code reviews - Debug production issues with urgency; own them until they're fixed COLLABORATE - Work closely with product, design and backend engineers - Pick up backend work (Python) when a feature needs it WHAT WE'RE LOOKING FOR MUST-HAVE: - 0-2 years of building and shipping web products in production - Strong JavaScript, TypeScript and React, including performance and state management - Good HTML and CSS, with mobile-first, responsive layouts - Good understanding of how browsers work on mobile, including camera access, permissions and cross-browser issues - Solid problem-solving and DSA fundamentals - You care about user experience and notice when a flow feels off NICE-TO-HAVE: - Flutter or React Native experience - Experience building an SDK or library that other developers use - Experience with camera, video or document scanning features - Some backend experience in Python or Node.js - Background in FinTech or identity verification WHY AIPRISE - Build mission-critical software that directly fights financial crime and fraud for companies like Meta and leading fintechs - Work with users and data from 200+ countries - Join a fast-moving YC-backed startup where your work has immediate customer impact - Ship quickly. Your code will reach production in days, not months - Collaborate in-person with a talented, mission-driven team in Bengaluru - Competitive compensation ABOUT THE INTERVIEW 1. Remote: Exploratory Discussion 2. In-office 1. DSA/Problem Solving 1 2. DSA/Problem Solving 2 3. Frontend System Design 3. Remote: Behavioural (Head of Engineering) 4. Remote: Compensation Discussion
