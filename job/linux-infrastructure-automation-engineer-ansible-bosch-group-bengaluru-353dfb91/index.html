Linux Infrastructure Automation Engineer (Ansible)

Bosch Group · Bengaluru

About the role

Bosch Global Software Technologies Private Limited is a 100% owned subsidiary of Robert Bosch GmbH, one of the world's leading global supplier of technology and services, offering end-to-end Engineering, IT and Business Solutions. With over 27,000+ associates, it’s the largest software development center of Bosch, outside Germany, indicating that it is the Technology Powerhouse of Bosch in India with a global footprint and presence in the US, Europe and the Asia Pacific region. Roles &

Responsibilities

Install, configure, maintain, and troubleshoot Linux-based systems, preferably on Ubuntu 22.x or higher versions. Perform software installation, upgrades, deployment, and issue resolution for enterprise applications and services. Maintain and support Web Application Servers hosted on Linux environments. Configure and manage TLS/SSL encryption, certificates, and secure communication channels for web applications and servers. Apply security patches, system updates, and vulnerability fixes across Linux infrastructure. Define, document, and implement standardized patch management and patch distribution processes. Develop and maintain automation solutions using Ansible for configuration management, deployment, patching, and server administration activities. Create and maintain automation scripts using Shell scripting or Python for operational and infrastructure tasks. Troubleshoot network-related outages and connectivity issues involving routers, switches, VLANs, DNS, firewalls, and related components. Ensure system availability, security compliance, and operational reliability across environments. Collaborate with development, infrastructure, and security teams for deployment, maintenance, and operational activities.   Educational qualification: B.E./M.Tech in CSE, ECE, EEE or related discipline Typical experience level: 6-8 yrs   Mandatory Skills: Strong Ubuntu Linux experience(22.x or higher) Strong Ansible experience Patch Management Strong Networking fundamentals and troubleshooting skills Strong Scripting automation experience (bash, python) Web Server & Security Experience in maintaining Linux-based Web Application Servers with TLS/SSL encryption  Design, develop, and maintain enterprise Ansible automation frameworks. Develop reusable playbooks, roles, collections, and modules following best practices. Build scalable, idempotent automation for provisioning, configuration management, application deployment, and OS lifecycle management. Automate software installation, upgrades, patching, and rollback processes. Manage Ansible inventories, variables, templates, Ansible Vault, and execution environments. Optimize Ansible performance for large-scale deployments across hundreds of Linux systems. Troubleshoot and resolve complex automation failures. Maintain version-controlled automation using Git.   Preferred Skills: Docker container experience (dockerfile, building containers, troubleshooting, docker compose) Familiarity with CI/CD tools and infrastructure monitoring tools Exposure to DevOps and Infrastructure Automation practices Good-to-have Certifications:

Intermediate level: Red Hat Enterprise Linux Automation with Ansible

Specialist: Red Hat Certified Specialist in Managing Automation with Ansible Automation Platform
