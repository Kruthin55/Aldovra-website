Cloud Ops Analyst

Johnson Controls · Johnson Controls India COEE1

About the role

Cloud Operations Analyst Job Summary The Cloud Operations Engineer is responsible for the day-to-day management, monitoring, maintenance, security, and optimization of cloud infrastructure across Azure, AWS, GCP, and hybrid environments. The role ensures high availability, operational stability, security compliance, incident resolution, automation, and continuous improvement of cloud services supporting business-critical applications.

Responsibilities

align closely with enterprise Cloud Operations practices involving infrastructure management, incident response, patching, vulnerability remediation, and operational governance. Key

Responsibilities

Cloud Infrastructure Operations Monitor and maintain cloud environments across Azure, AWS, and GCP. Manage virtual machines, storage, networking, load balancers, backups, and cloud services. Perform routine health checks and infrastructure capacity reviews. Ensure platform availability and service reliability. Incident & Service Management Troubleshoot and resolve cloud infrastructure incidents. Support P1-P5 incidents and service requests within SLA. Participate in Major Incident Management and Root Cause Analysis (RCA). Coordinate with vendors, application teams, and platform owners during outages. Patching & Vulnerability Management Execute server patching activities for Windows and Linux platforms. Drive vulnerability remediation initiatives. Ensure compliance with enterprise security standards. Support audit and regulatory requirements. Automation & Continuous Improvement Develop and maintain automation scripts using PowerShell, Python, Azure Automation, Terraform, or similar tools. Improve operational efficiency through self-healing and automated remediation. Reduce manual effort through workflow automation. Support Infrastructure as Code (IaC) adoption Monitoring & Observability Monitor cloud resources using enterprise monitoring tools. Configure alerts and dashboards. Analyze performance trends and recommend optimization actions. Ensure proactive issue detection and resolution. Backup, Disaster Recovery & Business Continuity Manage backup and recovery processes. Participate in DR planning and testing exercises. Ensure recovery objectives (RPO/RTO) are met. Support business continuity initiatives. Configuration & Asset Management Maintain CMDB accuracy and asset lifecycle management. Ensure proper ownership and support group mappings. Support compliance reporting and inventory management. Security & Compliance Implement cloud security best practices. Support identity and access management controls. Review security alerts and coordinate remediation activities. Support governance, risk, and compliance initiatives. Required Skills Technical Skills Azure, AWS, and/or GCP Administration Windows Server and Linux Administration Networking (DNS, Load Balancer, Firewalls, VPNs) Virtualization Platforms (VMware, Hyper-V) Monitoring Tools (Azure Monitor, SolarWinds, Dynatrace, etc.) PowerShell, Python, Bash Scripting Backup and Disaster Recovery Technologies ITSM Tools (ServiceNow, Jira) Process Skills ITIL Framework Incident Management Change Management Problem Management Service Request Fulfillment Operational Governance
