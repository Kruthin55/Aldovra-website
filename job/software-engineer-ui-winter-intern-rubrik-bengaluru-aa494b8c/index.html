About the role

About Company

Rubrik (NYSE: RBRK) is on a mission to secure the world’s data. With Zero Trust Data Security™, we help organizations achieve business resilience against cyberattacks, malicious insiders, and operational disruptions. Rubrik Security Cloud, powered by advanced AI and machine learning, secures data across enterprise, cloud, and SaaS applications - combining cyber resilience with generative AI to automate threat hunting, accelerate cyber recovery, and surface real-time data insights. Role: Software Engineer Intern - Core UI

Join our dynamic Core UI Engineering team to solve immense technical challenges and build award winning UI . Members of this team work on multiple product lines, build state of the art UI Infrastructure, focus on peak performance & AI-driven automation, and enhance our visualization portfolio & design library using TypeScript, React and GraphQL. As an intern, you will have the opportunity to contribute to various projects, learning and growing alongside world-class engineers while heavily leveraging AI coding assistants and automated testing tools in your daily development lifecycle.

Requirements

Currently pursuing a Bachelor’s or Master’s degree in Computer Science or a related field

Strong foundation in Computer Science fundamentals, including data structures, algorithms, and software design principles

Passionate about learning new technologies and tools, with a keen interest in front-end development and leveraging AI-assisted development workflows to ship high-quality code faster.

Good to have

Proficiency in developing and debugging in front-end technologies such as JavaScript, TypeScript, React, and GraphQL.

Fluency in HTML, CSS, and related web technologies.

Basic fluency in modern AI developer tools and prompt engineering, with an enthusiasm for integrating AI into day-to-day UI development.

Minimum eligibility criteria

CGPA 8 and above

2027 graduates of Circuital branches only

Available from January 2027 to May 2027 in Bangalore for the onsite internship (No remote options)
