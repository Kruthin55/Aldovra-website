Responsibilities

Design, develop, test, and maintain IAM software capabilities supporting AI and Agentic AI use cases. Partner with IAM technical leads and architects to implement defined identity and security patterns for emerging AI use cases. Build POCs and reference implementations to validate proposed authentication and authorization approaches. Implement identity and security standards such as OAuth 2.0, OpenID Connect (OIDC), JWT, token exchange, delegated authorization, and other emerging standards. Develop APIs, backend services, middleware, and reusable software components supporting AI-related IAM capabilities. Perform hands-on evaluation of emerging technologies and protocols such as MCP, A2A, and AI Agent frameworks from an IAM and security perspective. Integrate IAM capabilities with Identity Providers, enterprise applications, APIs, and AI platforms. Identify technical challenges and provide implementation feedback to IAM leads and architects to help refine security patterns and designs. Convert successful POCs into scalable, production-ready IAM capabilities. Develop reusable components and implementation patterns to simplify adoption of IAM capabilities across AI use cases. Collaborate with IAM, Security, AI, Architecture, and application engineering teams during implementation and testing. Apply secure coding, automated testing, CI/CD, observability, and software engineering best practices. Create technical documentation for POCs, implementations, integrations, and reusable components.
