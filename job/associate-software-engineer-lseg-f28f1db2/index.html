Associate Software Engineer

LSEG · BLR-Divyasree Technopolis, India

About the role

ROLE SUMMARY Are you an early-career software engineer who cares about writing good code and wants to learn from experienced engineers while building systems that matter? Join us at FTSE Russell! We’re building a team of engineers passionate about software craftsmanship, quality, and continuous improvement. As an Associate Software Engineer, you’ll contribute to the software that powers indices trusted by financial institutions worldwide, working alongside experienced engineers who will help you develop your technical skills and engineering judgement. We build primarily in Python, so experience with Python is valuable — but we’re equally interested in strong programming fundamentals and your ability to learn. If you’ve worked with Java, C#, C, C++, Scala, Go, Rust, or another modern programming language and are motivated to develop your Python skills, we’d like to hear from you. This is a hands-on engineering role. You’ll write, test, review, and improve production software as part of an experienced engineering team. You’ll learn how well-designed software is built and operated in practice — from clean code and automated testing to APIs, databases, cloud services, observability, and production support. You won’t be expected to know everything from day one. We’re looking for engineers with solid foundations, curiosity, and the willingness to learn, ask questions, take feedback, and gradually take ownership of increasingly complex work. If you’re excited about developing as a software engineer while building systems used in global financial markets, we’d love to meet you. WHAT YOU’LL BE DOING We’re building the next-generation index data platform at FTSE Russell — and you’ll help us build it: Writing clean, maintainable production code, primarily in Python, with guidance and support from more experienced engineers Building and enhancing software components, services, APIs, and shared libraries as part of a collaborative engineering team Writing automated tests and learning how to build software that is reliable, secure, and easy to maintain Participating in code reviews — learning from feedback on your own code and gradually developing the skills to review the work of others Investigating bugs and production issues, understanding root causes, and implementing well-tested fixes Working with relational databases such as Aurora PostgreSQL, learning good practices around data modelling, queries, and schema evolution Developing software running on AWS using technologies such as Lambda, containerised services, object storage, and other managed AWS services Contributing to data-intensive applications that process significant volumes of financial and index data Using CI/CD pipelines and development tooling to build, test, and deploy software safely Learning how observability, logging, monitoring, and quality controls help us operate reliable production systems Working closely with engineers, product colleagues, and other stakeholders to understand requirements and deliver useful solutions Taking part in design discussions and learning how experienced engineers evaluate technical options and trade-offs Building knowledge of financial indices and understanding how the software you develop supports our customers Continuously developing your engineering skills through hands-on work, feedback, pairing, and knowledge sharing WHAT YOU’LL BRING Essential — we’re looking for strong foundations and potential: A foundation in software development gained through professional experience, internships, graduate programmes, university projects, open-source contributions, or substantial personal projects Programming experience in Python or another modern language such as Java, C#, C, C++, Scala, Go, or Rust, together with a willingness to develop strong Python skills Understanding of core software engineering concepts such as functions, classes, data structures, APIs, error handling, and automated testing An interest in writing readable, maintainable code rather than simply making something work Basic understanding of software development practices such as version control, code review, testing, and debugging Familiarity with Git or another source control system Basic knowledge of relational databases and SQL An analytical approach to problem solving and the ability to break problems into smaller, manageable pieces Curiosity and willingness to learn new technologies, tools, and engineering practices Openness to feedback and an interest in learning from more experienced engineers Good communication skills and the confidence to ask questions when something is unclear A collaborative mindset — you enjoy solving problems with others and contributing to a supportive engineering environment We don’t expect Associate Engineers to arrive knowing our entire technology stack. Strong programming fundamentals, evidence that you enjoy building software, and the ability to learn are more important than having used every technology listed in this description. NICE TO HAVES Beneficial, but definitely not required: Experience building applications, APIs, services, or libraries in Python Familiarity with Python development practices such as type hints, pytest, linters, and dependency management Exposure to AWS or another public cloud platform Experience with PostgreSQL or another relational database Understanding of REST APIs and distributed or service-based architectures Experience with Docker or containerised applications Familiarity with CI/CD tooling such as GitLab CI, Jenkins, or GitHub Actions Exposure to infrastructure as code such as Terraform or AWS CDK Experience with data processing, ETL, or data-intensive applications Exposure to Pandas, Apache Spark / PySpark, or similar data-processing technologies Familiarity with object storage, data lakes, or technologies such as Apache Iceberg Contributions to open-source projects or personal software projects you can talk us through Experience in financial markets, financial data, or investment analytics An interest in financial markets and a willingness to learn the index domain Join us and be part of a team that values innovation, quality, collaboration, and continuous improvement. This role is an opportunity to build strong software engineering foundations, learn from experienced engineers, and gradually take on greater technical responsibility while contributing to software used across global financial markets.
