Quality Engineer

LSEG · BLR-Divyasree Technopolis, India

About the role

Position Overview The Quality Engineer is responsible for ensuring the delivery of high‑quality software through a combination of manual and automated testing practices. This role works closely with Development, Product, DevOps, and Delivery teams to validate functionality, improve test coverage, identify defects early, and continuously enhance the quality of products and platforms. The QE contributes to test strategy, builds automation frameworks, and helps foster a culture of quality throughout the engineering organization. Key

Responsibilities

Test Planning & Strategy Collaborate with Product Owners and Developers to understand requirements, acceptance criteria, and system behaviour. Participate in story refinement to ensure testability and clear acceptance criteria. Develop and maintain comprehensive test plans, test cases, and regression suites. Contribute to the overall QA strategy, including test coverage goals, automation priorities, and risk-based testing. Functional & Non‑Functional Testing Implement functional, regression, integration, system, and exploratory testing. Validate API responses, UI behaviour, workflows, and data integrity across environments. Perform non‑functional testing such as performance, usability, or basic security validation as needed. Ensure defects are clearly documented, reproducible, and communicated effectively. Test Automation Development Design, build, and maintain automated test suites using modern automation frameworks. Create and execute automated regression tests for UI, API, and service layers. Partner with Developers and DevOps to integrate automated tests into CI/CD pipelines. Ensure automation provides meaningful value by reducing manual effort and enabling early defect detection. Collaboration & Continuous Improvement Work closely with Developers to understand architecture, code changes, and risk areas. Collaborate with DevOps to ensure environments, data, and pipelines support effective testing. Participate in sprint ceremonies, defect triage, and release readiness activities. Drive improvements in test processes, tooling, automation, and engineering practices. Advocate for quality throughout the SDLC and promote shift‑left testing. Release & Production Support Validate builds and deployments in test environments; provide go/no‑go input for releases. Assist in root cause analysis for production issues and contribute to long‑term fixes. Monitor product quality trends and highlight risk areas or repeat issues. Skills &

Qualifications

Required 3+ years of experience in software testing or quality engineering. Solid understanding of QA methodologies, SDLC, and Agile (Scrum/Kanban). Experience creating functional and regression test cases; strong attention to detail. Familiarity with test automation tools (e.g., Selenium, Playwright, Cypress, Postman, Rest Assured). Experience testing APIs, web applications, or distributed systems. Ability to work collaboratively with multi-functional teams. Preferred Experience building automation frameworks (UI, API, or service-level). Knowledge of SQL for data validation and test setup. Experience with CI/CD tools (Azure DevOps, GitHub Actions, Jenkins). Familiarity with performance testing (JMeter, Gatling) or security testing tools. Experience in cloud environments (Azure, AWS). ISTQB, CSTE, or similar testing certification (optional).
