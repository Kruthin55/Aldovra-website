Responsibilities

Assist in coding, testing, and debugging software applications. Write clean, readable code following basic standards. Participate in Agile activities (stand-ups, sprint planning). Fix bugs and write simple unit tests. Implement small features/modules with guidance. Collaborate with the team to understand requirements. Analytical & Problem-Solving Skills: Strong analytical thinking to break down complex problems. Logical, methodical approach to coding challenges. Ability to debug systematically and think through edge cases. Comfortable with algorithmic problem-solving. Self-driven to research and learn independently. Personal Attributes: Curious and eager to learn new tools/technologies. Clear communicator, comfortable asking questions. Strong team player, open to feedback. Reliable with good time management. Ownership mindset and growth-oriented attitude. Nice to Have: Exposure to a web framework (Flask, Django, Node.js, etc.). Basic cloud platform awareness (AWS/Azure/GCP). Linux/command-line familiarity. GitHub projects or hackathon experience. Additional Information Relocation Assistance Provided: No
