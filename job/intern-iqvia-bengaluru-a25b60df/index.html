About the role

Job Description: AI/ML Intern Role Overview We are looking for an enthusiastic intern to apply classroom learning to practical AI/ML projects. You will work with experienced engineers to analyse data, test basic models, and build simple applications using AI-assisted tools. Key

Responsibilities

Prepare, clean, and analyse data using Python.

Assist in building and testing basic machine-learning models.

Use AI-assisted coding or low-code tools to develop simple applications and prototypes under guidance.

Review AI-generated code, test application outputs, and document findings.

Collaborate with the team and learn new tools as required. Required

Qualifications

and Skills

Currently pursuing a degree in Computer Science, Engineering, Mathematics, Statistics, or a related field.

Basic knowledge of Python programming.

Basic understanding of probability, statistics, linear algebra, and machine learning.

Willingness to learn, solve problems, and work in a team.

Ability to communicate ideas and document work clearly. Preferred

Qualifications

Experience with academic or personal projects involving data analysis, machine learning, or application development.

Exposure to pandas, NumPy, scikit-learn, or AI-assisted coding tools. No prior industry experience is required.
