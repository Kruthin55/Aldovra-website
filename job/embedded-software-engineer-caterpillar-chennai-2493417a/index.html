Embedded Software Engineer

Caterpillar · Chennai

About the role

Job Summary: As an Embedded Software Engineer at Caterpillar, you will develop embedded software for electronics control systems supporting engine programs. Areas of responsibility include configuration, integration, build, and testing of embedded software on engine systems; testing software for embedded electronic control systems includes requirements development and verification of software in a bench environment as well as troubleshooting software or system defects. This role requires experience in embedded systems, real-time software development, controls integration, and software lifecycle processes. The candidate will collaborate with systems and controls engineers driving the delivery of high-quality, production-ready software. Roles: Software Development · Perform Software requirements analysis to support the development of embedded software features. · Collaborate with controls engineers to integrate algorithms developed in MATLAB. · Perform software configuration and building of flash files. · Define and develop software in the loop test scripts. · Set-up and configuration of test bench hardware & software. Software Integration · Integrate software components, libraries, and auto-generated code into deployable software images and flash files. · Configure and manage software builds using embedded development toolchains. · Integrate calibration, configuration, and parameter datasets into embedded control applications. · Support software deployment to target hardware platforms and production ECUs. Verification & Validation · Execute software unit, integration, system, and regression testing. · Support Hardware-in-the-Loop (HIL), Software-in-the-Loop (SIL), and testing activities. · Develop comprehensive software test plans, validation procedures, and verification strategies. · Analyse test results and implement corrective actions as required. · Verify compliance with functional, performance, and safety requirements. Defect Analysis & Troubleshooting · Identify, investigate, and resolve software defects and system integration issues. · Perform root cause analysis of software, controls, and system-level failures. · Utilize debugging and diagnostic tools to troubleshoot embedded applications. · Support field issue resolution and continuous software improvement initiatives. Most suitable candidates will also have: · Degree in Electrical Engineering, Computer Engineering, or Computer Science · Experience with the following: C, and Python, Matlab, Git, Trace 32 Debugger, CANalyzer, Cat Electronic Technician (ET), CAN/SAE J1939, clear case · Experience working with and troubleshooting embedded electrical systems · Prior work experience with engine and/or machine software development Additional information: This job requires 5 working days from office This Job Description is intended as a general guide to the job duties for this position and is intended for the purpose of establishing the specific salary grade.
