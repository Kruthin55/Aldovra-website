Software Engineer (Python/Node.JS,AWS)

Autodesk · Pune

About the role

Job Requisition ID # 26WD102191 Position Overview Autodesk is building an artificial intelligence (AI)-first application platform that delivers connected experiences across its products and helps customers and internal teams work more effectively through agent-driven workflows. As a Software Engineer on our Pune engineering team, you will develop and enhance backend and platform capabilities that support agent-driven applications, workspace experiences, and integrations. You will collaborate with product managers, architects, and fellow engineers to translate technical and business requirements into reliable, scalable, and maintainable software solutions. You will contribute to services used across multiple products and teams while developing your expertise in modern backend technologies, distributed systems, and AI-enabled applications.

Responsibilities

Design, develop, test, and maintain backend features that support agent-driven applications and platform workflows Build and integrate Representational State Transfer (REST) application programming interfaces (APIs) and GraphQL services using Python, TypeScript, Node.js, or similar backend technologies Contribute to the design and implementation of data models, service integrations, and application workflows that connect AI agents, tools, and platform components Develop reliable backend services that support communication across distributed systems and asynchronous processes Write clean, readable, maintainable code and develop automated tests to ensure software quality Investigate software defects, troubleshoot service issues, and implement improvements to enhance system performance and reliability Contribute to monitoring and observability practices that support effective troubleshooting and service operations Participate in technical design discussions, code reviews, and engineering planning activities while incorporating constructive feedback Collaborate with product managers, architects, and engineering teams to translate requirements into incremental software enhancements Support continuous integration and continuous delivery (CI/CD) processes, cloud operations, and deployment activities Maintain technical documentation and contribute to the development of consistent engineering standards and best practices Work collaboratively with team members to identify opportunities for improving software quality, development efficiency, and service maintainability Minimum

Qualifications

3–5 years of professional software engineering experience, with a focus on backend application or service development Hands-on experience developing backend applications using Python, TypeScript, Node.js, or comparable technologies Experience developing or integrating REST APIs and familiarity with GraphQL Experience building or integrating backend services used by other applications, products, or engineering teams Familiarity with relational databases or non-relational (NoSQL) databases Exposure to cloud computing platforms, preferably Amazon Web Services (AWS) Understanding of distributed systems concepts, software testing, debugging, and version control practices Ability to investigate technical problems, implement effective solutions, and deliver maintainable, high-quality code Experience with AI-enabled applications, agent-driven workflows, tool integrations, or large language model (LLM) capabilities Familiarity with distributed systems patterns, asynchronous processing, event-driven architectures, or microservices Exposure to AWS services such as Amazon Bedrock, AWS Lambda, Amazon API Gateway, and Amazon CloudWatch Bachelor's degree in Computer Science, Engineering, or a related field, or equivalent practical experience Preferred

Qualifications
