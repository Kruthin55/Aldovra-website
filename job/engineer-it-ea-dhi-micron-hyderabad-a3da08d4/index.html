Engineer, IT EA DHI

Micron · Hyderabad

About the role

Our vision is to transform how the world uses information to enrich life for all . Micron Technology is a world leader in innovating memory and storage solutions that accelerate the transformation of information into intelligence, inspiring the world to learn, communicate and advance faster than ever. Software Engineer, IT EA DHI role focuses on building and enhancing data‑driven applications within Micron’s Enterprise Applications organization. The engineer will work primarily with .NET technologies and SQL Server to design, develop, optimize, and maintain applications supporting the Data Hub & Integration (DHI) team’s data warehousing and business intelligence needs.

Qualifications

& Experience: Strong conceptual knowledge in data structure & algorithms. Strong foundation in relational, NoSQL, graph databases as well as SQL. Strong programming concepts with knowledge of object oriented programming languages like C#, Python etc. Foundation in software architecture concepts and strong object oriented design patterns. Experience with Gen AI app development and concepts like RAG, Agents, MCPs, etc. Experience of web frontend technologies like JavaScript, react etc. Experience with cloud technologies, Azure, AWS etc. and cloud app deployments. Experience with micro-services architecture and associated concepts. Experience with HTTP APIs like REST APIs, GRPC as well as Remote Procedure Calls. Experience with API authentication and authorization protocols like OAuth 2.0 as well as tools like Microsoft Entra. Experience with Software version management tools like Git, Bitbucket etc. Experience with containerization tools like Docker. Experience with Scripting languages like PowerShell, bash. Ability to prioritize and meet critical project timelines in a fast-paced environment. Outstanding analytical thinking, interpersonal and written communication skills. Self-motivated and team-oriented. Ability to learn new concepts, programming languages on the fly. Good to Have : Knowledge of Snowflake, SQL Server database. Knowledge about Data visualization with Tableau/Power BI. Knowledge of Extract Load data pipelines. About Micron Technology, Inc. We are an industry leader in innovative memory and storage solutions transforming how the world uses information to enrich life for all . With a relentless focus on our customers, technology leadership, and manufacturing and operational excellence, Micron delivers a rich portfolio of high-performance DRAM, NAND, and NOR memory and storage products through our Micron® and Crucial® brands. Every day, the innovations that our people create fuel the data economy, enabling advances in artificial intelligence and 5G applications that unleash opportunities — from the data center to the intelligent edge and across the client and mobile user experience.
