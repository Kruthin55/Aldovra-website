Software Engineer I - Backend (Kirana Club)

Meesho · Bengaluru

About the role

About the Team We're a small engineering team, so scope is wide and ownership is real. You'll ship to production in your first week, and every week after that. Every engineering role here is back-end-leaning fullstack. Most of your time goes into services, data models and APIs, but you own your work all the way to the screen — and the screen should look like someone cared. If frontend hasn't been your main thing, that gap is far smaller than it used to be. What we can't teach is taste: the sense of what a good interface feels like, and the instinct to notice when something is confusing, slow or ugly before a user has to tell you. Everyone here writes code with LLMs — Claude Code, Codex, Cursor, whatever works, on the paid tier, and we don't count tokens. Producing code is cheap now, so what we hire for is judgment, verification, specification and taste. One hard rule: you own every line you ship, whether you typed it or not. "The model wrote it" is not an explanation in code review, in a postmortem, or in a design discussion.

About the role

This is a backend-leaning fullstack role, and a high-volume learning one. You'll build and ship features end to end — from the data model through the API to the screen someone actually uses — writing a lot of code and getting a lot of reviews. You'll be trusted with production early and work on real problems from your first week. The goal for your first year is simple: to become someone the team can hand an ambiguous problem to.
