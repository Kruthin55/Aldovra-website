QA Automation Engineer

LSEG · Bengaluru

About the role

Job Description Role Overview: We are looking for a strong, hands-on, highly motivated QA Automation Engineer to ensure the quality, reliability, and performance of the Service Layer (SL-QTC) platform supporting Quote-to-Cash (QTC), customer lifecycle, and enterprise integration workloads. You will be responsible for designing, developing, and maintaining automation frameworks and quality engineering practices for a cloud-native, event-driven platform built on AWS, Kafka/MSK, APIs, databases, and distributed microservices. You will work closely with Engineering, Product, Architecture, and DevOps teams to ensure robust test coverage, early defect detection, and high-quality releases. The ideal candidate combines strong automation expertise with experience testing distributed systems, event-driven architectures, cloud-native applications, APIs, and complex enterprise integrations.

Key responsibilities

Design, develop, and maintain scalable test automation frameworks for APIs, microservices, event-driven workflows, and cloud-native applications. Develop automated functional, integration, regression, end-to-end, and data validation test suites for Service Layer integrations and Quote-to-Cash business processes. Validate Kafka/MSK event flows, message transformations, canonical data models, database transactions, and downstream system integrations. Implement automated API testing, contract testing, service virtualization, and integration testing across enterprise applications and services. Integrate automated testing into CI/CD pipelines and collaborate with Engineering and DevOps teams to enable continuous quality and shift-left testing practices. Perform non-functional testing including performance, reliability, resiliency, and scalability testing of distributed systems. Develop automated data validation and reconciliation testing across PostgreSQL, ClickHouse, DynamoDB, and other platform data stores. Analyze defects, troubleshoot complex issues, perform root cause analysis, and drive quality improvements across the platform. Collaborate with cross-functional teams to define test strategies, quality standards, release readiness criteria, and engineering best practices. Contribute to continuous improvement of automation frameworks, test coverage, quality metrics, and release processes. Must Have Skills: Strong experience designing and developing test automation frameworks using Java, Python, TypeScript, or similar programming languages. Strong experience with API automation testing using tools and frameworks such as REST Assured, Postman, Karate, PyTest, Selenium, Playwright, or equivalent technologies. Strong experience testing microservices, distributed systems, and event-driven architectures, including Kafka, AWS MSK, RabbitMQ, or similar messaging platforms. Strong experience validating REST APIs, asynchronous workflows, message queues, data transformations, and enterprise integrations. Strong experience with PostgreSQL, relational databases, NoSQL databases, and data validation techniques, including query development and database testing. Experience implementing CI/CD-integrated test automation using GitLab CI, Jenkins, Azure DevOps, or equivalent platforms. Experience with AWS cloud services, including Lambda, API Gateway, S3, DynamoDB, RDS, SQS, SNS, CloudWatch, and serverless application testing. Experience with performance, load, reliability, and resiliency testing using tools such as JMeter, K6, Gatling, or equivalent solutions. Experience with test reporting, observability, and quality metrics using tools such as Allure, Grafana, Datadog, CloudWatch, ClickHouse, or similar platforms. Strong understanding of quality engineering principles, test strategy, test design, defect management, root cause analysis, and agile testing practices.

Qualifications

Bachelor's degree in Computer Science, Engineering, Information Technology, or related discipline. 7+ years of experience in Software Quality Assurance, Test Automation, or Quality Engineering roles. 4+ years of experience developing and maintaining automated testing solutions for enterprise applications and APIs. Experience testing cloud-native, distributed, and event-driven systems in production-scale environments. Experience working in Agile delivery environments with cross-functional engineering teams. Nice to have: ISTQB, Certified Agile Tester, AWS Certified Cloud Practitioner, or equivalent certifications. Experience implementing shift-left testing, test quality metrics, and quality gates within CI/CD pipelines. Experience testing Salesforce, Oracle ERP, OIC,ORMB, or enterprise integration platforms. Experience validating Kafka/MSK event streams, schema evolution, message contracts, and event orchestration workflows.
