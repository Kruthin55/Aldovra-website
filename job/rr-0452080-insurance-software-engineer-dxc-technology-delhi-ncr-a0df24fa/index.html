RR-0452080-Insurance Software Engineer

DXC Technology · Delhi NCR

About the role

Job Description: About the Role The Integration/Back-end Developer plays a key role in building and maintaining the backend services that power critical applications. This position focuses on developing robust, scalable, and secure server-side solutions using Java, Spring Boot, and the Spring Framework, while ensuring seamless integration with frontend applications through well-designed RESTful APIs. In this role, you will work closely with cross-functional teams, including DevOps, to deliver high-performing applications. You will be responsible for managing data across various database platforms, optimizing application performance, and applying security best practices throughout the development lifecycle. Your contributions will directly impact the reliability and efficiency of integration solutions supporting the business. This is an opportunity to work with a modern technology stack spanning backend frameworks, cloud services, and database technologies, while continuously improving system performance and collaborating within an agile development environment. Essential Job Functions Develop and maintain backend services using Java, Spring Boot, and Spring Framework. Design and implement RESTful APIs and integrate them with frontend applications. Work with MongoDB, MSSQL, and other NoSQL/SQL databases, including schema design, performance tuning, and indexing strategies. Optimize application performance and ensure adherence to security best practices. Test and debug APIs using Postman. Collaborate with DevOps teams to support deployment and infrastructure needs. Utilize AWS services such as S3, EC2, Lambda, IAM, API Gateway, and ECS. Apply performance engineering practices, including application monitoring and optimization. Develop additional components using Node.js, JavaScript, and TypeScript as needed. Basic

Qualifications

Experience with Java, Spring Boot, and Spring MVC Experience designing and implementing RESTful APIs Experience with Node JS, JavaScript, and TypeScript Proficiency with Postman and GIT Proficient in using IDEs like Eclipse Experience with AWS services like S3, EC2, Lambda, IAM, API Gateway, ECS Experience with MongoDB and MSSQL, including schema design, performance tuning, and indexing strategies Familiarity with performance engineering, application monitoring, and optimization Other
