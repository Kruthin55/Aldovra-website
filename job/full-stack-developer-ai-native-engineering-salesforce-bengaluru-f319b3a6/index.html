Full-Stack Developer — AI-Native Engineering

Salesforce · Bengaluru

About the role

To get the best candidate experience, please consider applying for a maximum of 3 roles within 12 months to ensure you are not duplicating efforts. Job Category Customer Success Job Details About Salesforce Salesforce is the #1 AI CRM, where humans with agents drive customer success together. Here, ambition meets action. Tech meets trust. And innovation isn’t a buzzword — it’s a way of life. The world of work as we know it is changing and we're looking for Trailblazers who are passionate about bettering business and the world through AI, driving innovation, and keeping Salesforce's core values at the heart of it all. Ready to level-up your career at the company leading workforce transformation in the agentic era? You’re in the right place! Agentforce is the future of AI, and you are the future of Salesforce. We are seeking an agile, end-to-end Full-Stack Developer to own the technical execution, rapid prototyping, and release lifecycle of our next-generation pre-sales scoping and estimation tool. As a core member of a lean engineering team, you will act as a "Full Stack" specialist, carrying direct responsibility for the entire application development lifecycle—spanning frontend construction, backend service integration, database configuration, deployment, and comprehensive quality assurance testing. Working under the guidance of the Technical Architect, you will leverage cutting-edge AI-augmented developer workflows to translate low-level designs into responsive web interfaces featuring embedded Claude plugin agents that securely interact with distributed systems. Key

Responsibilities

Rapid POC Implementation: Collaborate closely with the Technical Architect to quickly transform stakeholder requirements into functional, interactive Proof of Concepts (POCs) and operational prototypes. Design Execution & Modular Coding: Take ownership of Low-Level Designs (LLDs), converting software specifications into clean, maintainable, and highly modular code blocks utilizing modern JavaScript frameworks. Agent Embedded Development: Develop web-based application tiers featuring embedded Claude plugin agents. Implement unified cross-system data bridges using Model Context Protocol (MCP) to allow background reasoning loops to fetch context securely from external enterprise systems. API Integration & Authentication: Develop and consume robust RESTful services. Configure and execute precise authentication workflows supporting safe data transmission, strictly adhering to OAuth variants (including Username-Password flow, Web Server flow, and JWT flow). Database Management & Persistence: Design, optimize, and maintain relational or specialized database structures to provide optimal data persistence for scoping configurations and real-time computation states. CI/CD Pipeline Maintenance: Commit code, manage version control histories via Git, and interact with automated Jenkins build jobs to deploy software securely across SaaS platforms like Heroku. Quality Assurance & E2E Testing: Write and execute comprehensive unit, integration, and user-acceptance test profiles to maintain software stability within an accelerated, high-yield iteration cycle. Required Experience & Skills Professional Experience: Strong foundation in full-stack software development with explicit experience building and deploying multi-tier web applications from scratch. Advanced Web Framework Proficiency: Exceptional capability in Advanced JavaScript / TypeScript combined with operational mastery of web environments like Node.js, React, or AngularJS. AI Integration & Tooling Command: Practical experience consuming LLM APIs, prompt tracking, and integrating agentic plugins. Expert command of modern AI-augmented coding toolchains (such as Cursor or Claude Code) to accelerate feature shipping is highly valued. API and Security Foundations: Firm comprehension of REST architecture, relational database indexing, and common security authorization token exchanges (OAuth, JWT). DevOps and Lifecycle Discipline: Practical familiarity managing collaborative repositories using Git, navigating automated Jenkins pipelines, and hosting application artifacts on SaaS infrastructures like Heroku. Desired Experience & Certifications Background or technical familiarity with the Force.com infrastructure (Apex, Lightning Web Components, Data Cloud) is highly advantageous but not mandatory. Familiarity with Markdown documentation and grounding strategies for Large Language Models. Unleash Your Potential When you join Salesforce, you’ll be limitless in all areas of your life.
