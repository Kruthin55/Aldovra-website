Trainee Engineer

GE HealthCare · Bengaluru

About the role

Job Description Summary This role involves designing and developing embedded software (Control/Firmware) and software tools for X-ray generators within the Imaging Sub Systems group at GE HealthCare. The position requires knowledge of Embedded C, C++, and basic programming concepts, along with an understanding of digital electronics and schematics involving MCU/DSP-based systems. Candidates should be familiar with MATLAB and Simulink for control application development and simulation, and should have experience using Git. The role focuses on embedded software development, control applications, and HW integration. GE HealthCare is a leading global medical technology and digital solutions innovator. Our purpose is to create a world where healthcare has no limits. Unlock your ambition, turn ideas into world-changing realities, and join an organization where every voice makes a difference, and every difference builds a healthier world. Job Description Roles and

Responsibilities

Design, develop, and maintain embedded software (Control/Firmware) for X-ray generators within the Imaging Sub Systems group. Develop software tools required for configuration, testing, validation, and support of embedded systems. Implement software solutions using Embedded C, C++, and C programming languages for real-time embedded applications. Develop and simulate control applications using MATLAB and Simulink. Integrate and troubleshoot hardware drivers and support software-hardware interfacing activities. Work on Real-Time Operating Systems (RTOS) Support the development and implementation of control algorithms, including PI/PID-based control loops. Analyze and evaluate control system performance using tools and techniques such as Bode plots, Nyquist plots, and margin analysis. Work with digital hardware platforms involving MCUs, DSPs, and SoC devices (Xilinx/Intel). Required

Qualifications

Bachelor's/Master’s degree with Electronics/Electrical/Control Engineering or equivalent. Recent graduate or up to 1 year of relevant internship or experience. Knowledge of embedded software development and embedded system Programming experience in Embedded C, C++, and other C programming languages for real-time embedded applications.. Knowledge of MATLAB and Simulink for control application development and simulation. Good analytical and problem-solving skills. Strong communication and teamwork skills. Desired Characteristics Internship or relevant experience in Embedded Knowledge of embedded software development and embedded system Knowledge of MATLAB and Simulink for control application development and simulation. Experience in programming with C language and assembly language. Knowledge on control loops like PI/PID etc Basic understanding of control system analysis and margin analysis. Nyquist plots, Bode plots, etc. Basic understanding of digital schematics (MCU/DSP etc). Exposure to SoC devices (Xilinx/Intel) and experience in using Git.
