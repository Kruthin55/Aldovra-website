SFDC Developer

GE HealthCare · Bengaluru

About the role

Job Description Summary Own end-to-end Salesforce administration, including configuration, security, user access, and day-to-day platform operations. Design and maintain business automation using Flow, with hands-on support for reporting, analytics, and release management across environments. Enhance the platform with lightweight Apex, SOQL, and Lightning Web Components when configuration alone is insufficient. Partner with cross-functional teams to deliver secure, scalable integrations and compliant Salesforce solutions. Job Description Roles and

Responsibilities

In this role, you will: 1. Own day-to-day Salesforce administration, configure standard/custom objects, fields, record types, page layouts, Lightning apps, and user experience enhancements. 2. Build and maintain business automation primarily using Flow (record-triggered, scheduled, and screen flows); manage/retire legacy Workflow/Process Builder where applicable. 3. Administer and continuously improve the Salesforce security model: profiles, permission sets, permission set groups, roles, OWD, sharing rules, teams, FLS, and record-level access aligned to least-privilege. 4. Manage user lifecycle and access operations: onboarding/offboarding, license management, password policies, MFA/SSO coordination, and routine access audits. 5. Deliver reporting and analytics: create and optimize reports, dashboards, list views, and data visibility controls to check security and visibility controls and operational insights. 6. Support release execution across environments (sandbox → UAT → production): coordinate requirements, perform smoke/regression testing, document changes, and assist deployments (DevOps tools as used). 7. Provide developer-backed enhancements when configuration isn’t sufficient: implement lightweight Apex (classes/triggers) and SOQL/SOSL for complex logic, troubleshooting, and performance validation. 8. Support secure integrations with external systems: assist with requirements, field mapping, auth patterns awareness (OAuth/SSO concepts), and coordinate troubleshooting with integration teams. 9. Partner with architects, product owners, and compliance/security stakeholders to translate requirements into scalable, maintainable, and compliant Salesforce solutions. 10. Build UI improvements using Lightning Web Components (LWC) to streamline user workflows and improve usability.
