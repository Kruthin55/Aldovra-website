Processor Subsystem Development and Verification Engineer

Broadcom · Bengaluru

About the role

If you already have a Candidate Account, please Sign-In before you apply. Job Description: The position requires a breadth of disciplines and responsibilities in supporting the Processor based subsystem verification for the ‘ASIC Products Division’ within Broadcom Limited.

Responsibilities

will include Verification environment Development, Verification, Functional verification, performance verification, Coverage Closure, Gate simulations, releases, reviews etc. Typical subsystems are based on ARM processors like A72, A55, A53, R8, AMBA Bus matrixes like NOC, CCI, NIC and memory controllers like HBM, Memory management Units MMU/SMMU and various peripherals.

Responsibilities

will be both individual and team based with ability to work cross functionally across the organization. Requirements/Qualifications (Education) B.E/B.Tech/M.E/M.Tech in Electronics/VLSI Engineering with strong 6+ years of experience in Processor subsystem verification in both directed and random verification Experience in ARM Processor based subsystem verification using ARM asm and C language Good exposure to latest ARM processor architectures, Bus Interconnects and AMBA protocols – CHI, AXI, AHB, APB Experience in Verilog, System Verilog and UVM based testbench and environment development. Working knowledge of Verilog, and have programming skills in Perl and TCL scripting languages Expertise to develop block level / subsystem level verification environments using System Verilog and UVM is a must. Verification Knowledge of Security Root of Trust (RoT) based subsystem is an added advantage. Demonstrate the ability to work through technology challenges with high-performance design verification.
