Design Engineer

Sarvam AI · Bengaluru

About the role

ABOUT SARVAM Sarvam is building the bedrock of Sovereign AI for India. The company is developing India’s full-stack sovereign AI platform, building across research, models, infrastructure and applications with a singular focus on making AI genuinely work for India. Sarvam works with leading enterprises and public institutions and is backed by Lightspeed, Peak XV, and Khosla Ventures. Sarvam partners with India’s leading brands, including Tata Capital, SBI Life, CRED, IDFC, and LIC. ABOUT THE ROLE We're looking for a frontend developer with a designer's eye to build Sarvam's web experiences. You'll start with our marketing website: the homepage, product and use-case pages, interactive demos and calculators. You'll write production code, build reusable UI systems and turn rough ideas into polished interfaces, working closely with design, marketing and product engineering. KEY RESPONSIBILITIES - Build the interface, not just the mockup. Write production-ready Astro and React components with thoughtful layouts, typography and responsive behaviour. Own the implementation from first prototype to the final browser-sized detail. - Build a UI system that holds together. Create reusable components, layout primitives and shared styles with clear APIs and sensible variants. Make the next page easier to build without turning every component into a 40-prop puzzle. - Make it feel right. Build interactions, transitions and animations that make interfaces clearer and more enjoyable. Think through keyboard use, loading, empty and error states, reduced motion and what happens when the happy path isn't so happy. - Prototype in code. Explore alternative layouts and interactions with designers, test ideas in the browser and refine the details together. You should be comfortable suggesting a better implementation, not waiting for every pixel and breakpoint to be specified. - Build the useful bits properly. Develop interactive demos, calculators and forms; connect thm to APIs and content. Handle state, validation, asynchronous behaviour and failures. Keep accessibility, performance, metadata and measurement working as part of what you ship. - Own the engineering quality. Make sound choices about component structure, rendering and hydration. Debug browser and performance issues, write appropriate tests, review code and check preview deployments. Ship maintainable changes that work beyond your own laptop. - Astro, React, TypeScript and CSS are at the core of the work. We use GitHub for code review and Railway for development and pull-request previews. Sanity, ImageKit and PostHog support content, media and measurement. You'll work with engineering on staging and production releases. REQUIREMENTS - Have built and shipped interfaces you're proud to put your name on. Show us the actual thing, what you coded and the decisions you made. A live link beats a paragraph of adjectives. - Have strong HTML, CSS, JavaScript and TypeScript fundamentals and hands-on React experience. You can work effectively in Astro and reason about component composition, state, rendering and browser behaviour. - Have a good eye for visual design and the CSS skills to act on it. You care about spacing, type, hierarchy, responsive layouts and interaction details, and can turn that judgement into working code. - Can work across design and engineering. You're comfortable starting from a rough brief, prototyping options and discussing trade-offs with designers. You can also take an established design and implement it faithfully. - Can debug an unfamiliar frontend, integrate APIs and use Git, pull requests and automated checks confidently. You understand accessibility and web performance, and handle credentials and user data responsibly. - Use AI coding tools with judgement. Let them help you move faster. Read the diff, test the result and be able to explain what you're shipping. 'The model wrote it' isn't a debugging strategy. - Ask good questions when the brief is fuzzy. Explain trade-offs, suggest a practical way forward and use evidence before declaring that something needs fixing. BONUS POINTS THAT ARE NOT DEALBREAKERS - You've built for B2B SaaS, developer tools or AI products. - You've built component libraries, design systems or interactive prototypes that other people actually use. - You've worked with animation, SVG, Canvas or other techniques that make complex ideas easier to explore on the web. - You've used a headless CMS such as Sanity, or worked on technical SEO and analytics integrations without letting them take over the frontend. HOW TO APPLY Skip the generic cover letter. Send us a couple of interfaces or web projects you've built, with a short note on what you personally designed and coded. Pick one and walk us through a component, interaction or tricky engineering decision. Code samples are welcome where you can share them. If there's a side project you're weirdly proud of, we'd like to see that too. WHY SARVAM? Sarvam is a fast-moving, high talent-density team building full-stack AI for India, working on problems that push the frontiers of AI with real population-scale impact. - Work alongside researchers, engineers, builders, and business leaders who move fast and hold each other to a very high bar - High ownership and high impact, from day one - Everything we do is AI-first, from the way we build and ship to the way we think about problems - You can work on problems that could change how an entire country learns, works, and communicates If you want to work on problems at the frontier of AI in India, Sarvam is the place to be.
