IT Analyst

Johnson Controls · Pune

About the role

Job Title: SAP ABAP Analyst Location : Pune Employment Type : Full-time Role Summary: We’re looking for an SAP ABAP Developer with 1-6 years of hands-on experience in designing, developing, and optimizing SAP custom objects on ECC or S/4HANA. The ideal candidate is strong in ABAP OO, enhancements, and integration objects, with solid debugging and performance tuning skills. Key

Responsibilities

Design, develop, and unit test ABAP objects: reports, interfaces, conversions, enhancements, forms (RICEF).

Build and maintain BAPIs, BAdIs, User Exits, Enhancements (Implicit/Explicit), Enhancement Spots, and Business Object Enhancements.

Develop ALE/IDoc interfaces, work with OData integrations.

Create and optimize Open SQL, ABAP OO, AMDP/CDS-based logic for S/4HANA compatibility and performance.

Develop forms using Adobe Forms and Smart Forms; handle SAP Script where needed.

Build CDS Views (Basic/Cube/Consumption) and expose to Fiori/OData where applicable.

Perform performance tuning (SQL trace, ST05, SAT/SE30, buffer/DB hints); ensure Clean ABAP and secure coding.

Collaborate with Functional, Basis, and Integration teams through full SDLC; prepare technical specs (TSDs).

Participate in transport management (CTS/ChaRM), defect triage, and release cycles.

Provide L2 support: root-cause analysis, bug fixes, emergency transport handling. Required Skills

Core ABAP: ABAP OO, Open SQL, modularization, ALV (OO), BAPIs, BAdIs, Enhancements, RFCs, IDocs, Batch Jobs.

S/4HANA: CDS Views, AMDP, ABAP 7.5x syntax, New Open SQL, code pushdown concepts.

Forms: Adobe Forms, Smart Forms.

Tools: ADT (Eclipse), SE80, CTS/ChaRM, ST05/SAT.

Integration: OData, ALE/IDoc.

Quality: Unit testing, performance tuning, secure coding, Clean ABAP guidelines.

Process: Agile/Scrum, Jira/Azure DevOps (or similar), Git basics preferred. Nice to Have

Exposure to SAP Fiori (UI5 consumption of OData), Workflow, BRFplus.

S/4HANA Conversion experience (Custom code remediation using ATC/SPAU/SPDD).

Domain exposure (e.g., MM/SD/FI/PP/QM/WM/EWM) for solutioning RICEF objects.
