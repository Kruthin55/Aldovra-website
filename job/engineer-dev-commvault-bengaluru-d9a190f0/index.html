Engineer – Development, Indexing (C++ / SQL)

Experience: 0–2 years; Fresh graduates are welcome

Location: Bangalore

The Opportunity

We are looking for an Engineer to join our Indexing team. You will contribute to software that organizes and retrieves data efficiently, with a focus on correctness, performance, and reliability. You will also develop automation to improve testing, validation, and engineering workflows.

This role is suited to an early-career developer with strong C++ and SQL skills, a systematic approach to development, and the curiosity to ask what could go wrong and how to test it.

What you’ll do

Develop and maintain indexing components using C++ and SQL.

Build and maintain automated tests, validation scripts, and tools that reduce repetitive work.

Investigate defects by reproducing issues, examining logs, stepping through code, and identifying root causes.

Write SQL queries to retrieve, validate, and troubleshoot data.

Design test cases covering expected behaviour, boundary conditions, invalid inputs, and failure scenarios.

Add unit and regression tests to validate changes and prevent recurring defects.

Work with developers and QA engineers to clarify requirements, review changes, and resolve issues.

Communicate findings, explain technical decisions, and document your work clearly.

Who you are

A fresh graduate or developer with up to two years of software development experience. Relevant academic projects and internships are welcome.

Proficient in C++, including object-oriented programming, STL containers, pointers, references, and memory management.

Comfortable writing SQL queries using joins, aggregations, and subqueries, with an understanding of relational database fundamentals.

Strong in data structures, algorithms, and logical problem-solving.

Able to debug methodically, test assumptions, and explain how you arrived at a solution.

Able to translate a requirement into varied test scenarios, including empty or duplicate data, boundary values, large inputs, and interrupted operations.

Interested in automation and identifying opportunities to improve testing and development efficiency.

Clear in written and verbal communication, willing to ask questions, and receptive to feedback.

Curious about unfamiliar code and motivated to learn.

Good to have

Familiarity with Python for scripting, automation, or testing.

Exposure to test automation frameworks.

Understanding of indexing, search, database internals, or storage systems.

Familiarity with multithreading, concurrency, and operating system fundamentals.

Experience using Git and a debugger such as GDB or Visual Studio.

Projects or internships demonstrating C++, SQL, debugging, automation, or thoughtful testing.
