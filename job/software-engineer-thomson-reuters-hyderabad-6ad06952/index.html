Software Engineer

Thomson Reuters · Hyderabad

About the role

Job Description: The Commercial Engineering Integrations team within Thomson Reuters' CIO organization builds and supports integration solutions that power critical business capabilities across platforms such as Salesforce, SAP, and Adobe Experience Manager. We are seeking an Apigee Software Development Engineer to design, develop, and support scalable API solutions on the Apigee platform, enabling secure and reliable integrations across enterprise applications. Key

Responsibilities

Design, develop, configure, and support APIs using Apigee. Implement API security, traffic management, versioning, and integration best practices. Develop and test API proxies, policies, and custom integrations with backend systems. Troubleshoot and resolve API performance, security, and production issues. Monitor API health, usage, and scalability; optimize performance where needed. Collaborate with cross-functional teams, vendors, and stakeholders to deliver integration solutions. Create technical documentation and contribute to continuous process improvements. Required

Qualifications

3-5 years of software development experience with API management platforms such as Apigee. 2+ years of hands-on experience with Apigee, including API proxies, policies, developer portals, and management tools. Strong understanding of RESTful APIs, API lifecycle management, versioning, and documentation standards. Proficiency in Java, JavaScript, or Python. Experience troubleshooting complex API, integration, and production support issues. Strong communication and collaboration skills. Shift time: 12:30 to 9:30 Preferred Qualification s: Experience with enterprise integrations involving Salesforce, SAP, Adobe Experience Manager, or similar platforms. Knowledge of API security, authentication, authorization, and data encryption standards. Experience leading technical initiatives and mentoring team members. Familiarity with modern cloud-based integration and API management architectures.
