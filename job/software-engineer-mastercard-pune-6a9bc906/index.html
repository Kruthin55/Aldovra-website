Overview Payments Network Technology is seeking a Software Engineer in Test to design, develop, and maintain automation solutions for payment processing platforms. The role focuses on building scalable test frameworks and automated validation for authorization, clearing, tokenization, APIs, user interfaces, and end-to-end payment transaction flows. Roles and

Responsibilities

Design, develop, and maintain reusable automation frameworks using Java and modern test automation tools.

Build automated functional, API, integration, regression, and UI test suites.

Develop automated validation for ISO 8583 messages, authorization, clearing, tokenization, and payment processing workflows.

Translate business requirements and user stories into effective automated test coverage.

Integrate automated tests into CI/CD pipelines and release quality gates.

Analyze failures, troubleshoot issues, and partner with software engineers to drive resolution.

Manage test data, environments, and automation assets to support reliable and repeatable execution.

Improve automation coverage, framework capabilities, and engineering efficiency. Essential Skills

Strong programming skills in Java with experience developing automation frameworks and test utilities.

Hands-on experience with Cucumber, Selenium, Karate, JUnit/TestNG, Rest Assured, or similar automation technologies.

Experience testing REST APIs, microservices, web applications, and database-driven systems.

Knowledge of Git, CI/CD pipelines, DevOps practices, and modern software development methodologies.

Experience with SQL and test data management.

Understanding of ISO 8583 messaging, authorization, clearing, tokenization, or payment processing is preferred.

Scripting experience using Python, Shell, or similar technologies is a plus. All About You

Bachelor's degree in Computer Science, Engineering, or related field, or equivalent practical experience.

Hands-on engineer with a passion for software quality, automation, and continuous improvement.

Experience working in Agile environments across the software development lifecycle.

Strong communication, collaboration, debugging, and problem-solving skills.

Ability to work effectively with globally distributed engineering, product, architecture, and operations teams.

Experience applying AI-assisted engineering tools, including GitHub Copilot and Claude CLI.

Payments or financial services domain experience is preferred.
